## Домен, TLS и доступность из России (состояние 17.08.2026)

Домен `mediashkola.pro` — зона Cloudflare (DNS-only), четыре A-записи apex на GitHub Pages
`185.199.108–111.153` + CNAME `www`. Сертификат — Let's Encrypt через GitHub Pages,
`CN=mediashkola.pro`, выпущен 17.08, до 15.11.2026. Приёмник заявок — Cloudflare Worker
`msh-lead` на `api.mediashkola.pro` (Custom Domain, свой сертификат Cloudflare).

**Enforce HTTPS намеренно ВЫКЛЮЧЕН.** Замер с российских узлов (check-host, три узла,
по три прогона, 17.08): TCP до `185.199.x.153:443` устанавливается за 20–40 мс, но
TLS-запрос к `mediashkola.pro` и `*.github.io` на двух московских узлах виснет по таймауту
(15–16 с), а по `http://` те же узлы отдают страницу за 30–90 мс. Контроль: `github.com`
и `api.mediashkola.pro` отвечают 200 со всех узлов. Значит, режется не IP, а TLS по SNI —
волнами, на части сетей. Совпадает с данными OONI о росте отказов к GitHub в РФ с 05.05.2026.

Следствие: при включённом Enforce HTTPS `http://` отдавал 301 на `https://`, который на таких
сетях не открывается вовсе — сайт становился недоступен. С выключенным работают оба протокола:
кто дотягивается до 443, видит валидный сертификат; кто нет — получает страницу по http.

Это компромисс, а не решение. Решение — хостинг, достижимый из России (сайт статический,
переносится копированием). До переноса не включать Enforce HTTPS и не ставить canonical/og:url
с жёстким `https://` — они прибьют пользователя к недостижимому протоколу.

## Непрерывные ленты — 03.10.2026

`assets/motion-loops.js` управляет верхней фотолентой и существующими отзывами.
Все18 фотографий проходят в одном цикле, начиная с четырёх выбранных портретов;
все9 отзывов и их текст сохранены. Два равных набора включают конечный зазор,
поэтому переход через конец совпадает геометрически. Движется только transform:
30px/s фотографии, прежние27px/s отзывы. Скорость не зависит от размера окна.

Ленты автоматически движутся с первого открытия и после перезагрузки. Кнопок
запуска/паузы нет; hover, системный reduced motion и старые значения msh-motion-*
не останавливают их. Для клавиатуры все фото доступны через полную галерею;
визуальные дубли исключены из tab-order и accessibility tree.

Hero сохраняет исходную хореографию Claude20af1a3: после500ms зачёркивание350ms,
после1000ms допечатка900ms/11шагов, затем курсор гаснет к4000ms. Играет один раз
при каждом открытии, включая reduced motion. Числовая ширина текста сохраняет
последнюю точку. На телефоне курсор скрыт, как в исходнике. Остальные эффекты
продолжают учитывать системную настройку.

`node tools/check-motion-loops.cjs <url> <out> cycles` проверяет320/390/1280,
оба motion preference, автозапуск без кликов, старый saved pause, hover, resize
и два естественных полных оборота без ускорения времени. `check-hero-motion.cjs`
сэмплирует реальные стадии intro на320/1024/1440 с обеими настройками.
`check-selected-site.cjs` проверяет галерею, intro, календарь и курс.
Реальные заявки при проверках не отправляются.

## Цветовая иерархия

`DESIGN.md` и `data/tokens.json` задают цветовые роли для обеих страниц. Яркая
фуксия появляется в шапке любого курса при наведении или фокусе; тёмная фуксия — в действиях с мелким
текстом. Розовые и тёмные поверхности чередуются с белыми разделами.

`node tools/check-color-system.cjs <url> <out>` проверяет вычисленный контраст (включая прозрачность цветов),
иерархию курсов и записи, клавиатурный фокус,320/390/768/1440, сохранение исходных
текстов и ссылок, затем сохраняет изображения всех разделов main/kurs на390/1440.
Смена цветов не затрагивает скрипты анимаций, календарные данные и транспорт формы.

| Было | Стало | Зачем |
|---|---|---|
| Розовый «Медиа» и чёрная шапка «Оратора» | Одинаковые белые карточки, тонкие линии фуксии и розовые плашки возраста | Оба курса равноценны, ни один не выглядит выбранным заранее |
| Постоянная заливка шапок | Одинаковое проявление фуксии за 200 ms при hover; клавиатурный фокус без задержки | Цвет следует вниманию, как у фотографий |

`node tools/check-course-parity.cjs <url> <out>` проверяет одинаковое спокойное
состояние, наведение на каждый курс и возврат, клавиатурный фокус, отсутствие
залипающего hover на touch, контраст и работающие ленты. Размеры 320/390/768/1440,
обычная настройка движения и reduced motion; без отправки форм.
